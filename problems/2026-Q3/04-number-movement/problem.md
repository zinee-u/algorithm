# 숫자의 이동과 합치지

> 사용자 기억과 공유 대화에서 확인한 규칙을 바탕으로 정리한 연습 문제입니다. 공식 출제문이나 공식 채점 데이터가 아닙니다. 원래 시험의 입력 상한은 확인되지 않았으며, 아래 입력 범위는 연습용으로 정했습니다.

## 문제

일렬로 놓인 `N`개 칸의 상태를 나타내는 정수 배열 `numbers`가 주어집니다. `numbers[i]`는 `i`번 칸의 숫자이며, `0`은 숫자가 없는 빈 칸입니다. 칸의 인덱스는 `0`부터 `N - 1`까지입니다.

매 시간 다음 과정을 진행합니다.

1. 모든 양수는 오른쪽으로 한 칸, 모든 음수는 왼쪽으로 한 칸 **동시에** 이동합니다.
2. 경계를 넘어간 숫자는 사라집니다. 왼쪽으로 나갔는지 오른쪽으로 나갔는지에 따라 탈출 개수를 하나 늘립니다.
3. 이동을 마친 뒤 같은 칸에 도착한 숫자들은 합쳐져, 합을 값으로 갖는 숫자 하나가 됩니다.
   - 합이 `0`이면 사라져 빈 칸이 됩니다.
   - 합이 `0`이 아니면 다음 시간부터 합의 부호에 따라 이동합니다.

**이동 중 서로 엇갈려 지나간 숫자는 합쳐지지 않습니다.** 예를 들어 인접한 칸의 `[1, -1]`은 한 시간이 지나면 `[-1, 1]`이 됩니다.

모든 숫자가 사라질 때까지 진행한 뒤, **`[왼쪽으로 나간 숫자의 개수, 오른쪽으로 나간 숫자의 개수]`**를 반환하세요.

- 합쳐진 숫자가 탈출하면 값의 크기나 원래 숫자 수와 관계없이 **하나**로 셉니다.
- 합이 `0`이 되어 사라진 숫자는 탈출 개수에 포함하지 않습니다.
- 처음부터 모두 `0`이면 `[0, 0]`을 반환합니다.

## 함수

Python:

```python
def solution(numbers):
    # [왼쪽 탈출 개수, 오른쪽 탈출 개수]를 반환합니다.
    pass
```

C++17:

```cpp
vector<int> solution(vector<int> numbers);
```

Python은 정수 두 개를 담은 `list`, C++은 크기가 2인 `vector<int>`를 반환합니다. 표준 입력·출력 대신 함수의 반환값을 작성합니다.

## 제한사항

- **연습용 입력 범위:** `1 ≤ len(numbers) ≤ 100,000`, `-10^9 ≤ numbers[i] ≤ 10^9`.
  - 원래 시험의 입력 상한은 확인되지 않았습니다.
- 모든 숫자는 동시에 이동하며, 이동 후 같은 칸에서만 합쳐집니다.
  - 이 규칙은 공유 대화에서 사용자가 정정·확인한 조건입니다.
- `0`은 움직이는 숫자가 아니라 빈 칸입니다.
  - 합이 `0`인 충돌은 탈출 개수에 포함하지 않습니다.
- 반환 순서 `[왼쪽, 오른쪽]`과 개수 기준은 공유 대화의 제출 코드 해석을 채택한 복원 조건입니다.
- 기억한 시험 제한은 **10초·2GB**입니다. 확인된 공식 제한은 아닙니다.
  - 시간 단위로 전체 배열을 반복 갱신하면 큰 입력에서 느릴 수 있습니다.
  - 로컬 채점에서는 `--timeout 10`으로 테스트당 10초를 설정할 수 있습니다. 메모리 상한은 강제하지 않습니다.

## 입출력 예

아래 여섯 사례는 이 연습 문제의 규칙을 설명하기 위해 만든 자체 복원 예제입니다. 공식 예제가 아닙니다.

| 예제 | `numbers` | 반환값 |
| --- | --- | --- |
| 1 | `[0]` | `[0, 0]` |
| 2 | `[1, -1]` | `[1, 1]` |
| 3 | `[3, 0, -3]` | `[0, 0]` |
| 4 | `[5, 0, -3]` | `[0, 1]` |
| 5 | `[2, 0, -5]` | `[1, 0]` |
| 6 | `[4, 0, 3, 0, -5]` | `[0, 1]` |

## 예제 1 설명

처음부터 숫자가 없으므로 왼쪽과 오른쪽으로 나가는 숫자가 모두 0개입니다.

## 예제 2 설명

첫 번째 시간이 지나면 `[1, -1]`은 `[-1, 1]`이 됩니다. 두 숫자는 서로 엇갈려 지나갔으며, 이동 후 서로 다른 칸에 있으므로 합쳐지지 않습니다.

두 번째 시간에 `-1`은 왼쪽 경계, `1`은 오른쪽 경계를 넘어갑니다. 따라서 `[1, 1]`을 반환합니다.

## 예제 3 설명

첫 번째 시간에 `3`과 `-3`이 가운데 칸으로 동시에 이동합니다. 합이 `0`이므로 둘 다 사라집니다. 경계를 넘어간 숫자는 없어 `[0, 0]`을 반환합니다.

## 예제 4 설명

첫 번째 시간에 가운데 칸에서 `5 + (-3) = 2`가 되어 `[0, 2, 0]`이 됩니다. 다음 시간부터 `2`는 오른쪽으로 이동하고, 세 번째 시간에 오른쪽 경계를 넘어갑니다.

원래 두 숫자가 합쳐졌지만 탈출한 숫자는 하나이므로 `[0, 1]`을 반환합니다. 값인 `2`를 탈출 개수로 세지 않습니다.

## 예제 5 설명

첫 번째 시간에 가운데 칸에서 `2 + (-5) = -3`이 되어 `[0, -3, 0]`이 됩니다. 이후 `-3`이 왼쪽으로 이동해 세 번째 시간에 왼쪽 경계를 넘어갑니다. 따라서 `[1, 0]`을 반환합니다.

## 예제 6 설명

각 시간이 끝난 뒤의 배열과 누적 탈출 개수는 다음과 같습니다.

| 시간 | 배열 상태 | 누적 `[왼쪽, 오른쪽]` |
| --- | --- | --- |
| 시작 | `[4, 0, 3, 0, -5]` | `[0, 0]` |
| 1 | `[0, 4, 0, -2, 0]` | `[0, 0]` |
| 2 | `[0, 0, 2, 0, 0]` | `[0, 0]` |
| 3 | `[0, 0, 0, 2, 0]` | `[0, 0]` |
| 4 | `[0, 0, 0, 0, 2]` | `[0, 0]` |
| 5 | `[0, 0, 0, 0, 0]` | `[0, 1]` |

첫 번째 시간에 `3`과 `-5`가 합쳐져 `-2`가 됩니다. 이 숫자는 두 번째 시간에 왼쪽으로 이동하여 `4`와 합쳐지고, `2`가 됩니다. 세 번째 시간부터 오른쪽으로 이동해 마지막에는 숫자 하나만 탈출합니다.
